name: simanalysis
description: Describe the format of XiangShan processor performance counter outputs (e.g., simulator_err.txt).
---

The simulator_err.txt file is the performance counter output generated by the XiangShan processor. It contains performance counters of interest defined by developers across different modules. Each counter appears twice: the first occurrence corresponds to the warmup phase, and the second corresponds to the actual simulation, which is used for performance evaluation. According to the given requirements, compare the provided simulator_err.txt.
